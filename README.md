# C programming

Everything I wrote while learning C, from the basics to pointers and structs. Each file is a small, self-contained
program.

- **Basics**: I/O, loops, switch, even/odd, prime/composite, Armstrong and palindrome numbers, HCF, powers
- **Recursion**: factorial, Fibonacci, sum of n, Tower of Hanoi, maze paths, recursive palindrome
- **Arrays and matrices**: 2D input/output, transpose, multiplication, max element, pairs and triplets, unique element, wave printing
- **Strings**: length, vowels, comparison, substrings, insertion, strings as pointers
- **Pointers and structs**: swapping through pointers, nested structs, arrays of structs, struct pointers, typedef
- **Small projects**: a food-ordering system in the terminal

Build: `gcc file.c -o out && ./out`
